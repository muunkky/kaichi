Stop conditions — exhaustive
Anything not listed is a normal autonomous action.
  1. kaichi MCP unavailable or erroring
  2. Gate 0 FAIL / INPUT_ERROR / EXTERNAL_PROBE_ERROR / uncaught exception
  3. Missing sprint closeout card
  4. Missing WorktreeCreate hook

  10. Sprint adding cards faster than it closes them
